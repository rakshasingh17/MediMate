# MediMate 🩺

MediMate is an AI-powered healthcare web application that provides instant risk assessments for **Diabetes, Heart Disease, and Lung Cancer** using intelligent AI analysis.

Built with **HTML, CSS, JavaScript, Node.js, Express, and Groq AI**, the platform delivers a responsive user experience with AI-generated health insights, emergency guidance, and responsible AI disclaimers.

---

## ✨ Features

* Diabetes risk prediction
* Heart disease risk prediction
* Lung cancer risk prediction
* AI-generated health assessments
* Responsive and mobile-friendly UI
* Emergency contact section
* Medical disclaimer and responsible AI guidance
* Fully deployed web application

## ⚙️ How It Works

1. User selects a disease category
2. Health parameters are entered into the form
3. Data is sent to the Node.js backend
4. The backend communicates with the AI model
5. AI generates a structured risk assessment
6. Results are displayed instantly on screen
